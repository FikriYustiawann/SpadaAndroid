SPADA UNTIRTA Android

Aplikasi Android berbasis WebView untuk memudahkan akses website "SPADA UNTIRTA" (https://spada.untirta.ac.id/?redirect=0) langsung melalui HP Android.

📥 Download Aplikasi

"Klik di sini untuk Download SPADA UNTIRTA" (https://github.com/FikriYustiawann/SpadaAndroid/releases/latest/download/SPADAUntircoy-APK.2.zip)

📱 Cara Instalasi

1. Klik link download di atas.
2. Tunggu hingga file ZIP selesai diunduh.
3. Buka file ZIP, lalu ekstrak isinya.
4. Cari file APK di dalam folder hasil ekstraksi.
5. Buka file APK untuk memulai instalasi.
6. Jika Android meminta izin instalasi dari sumber tersebut, buka pengaturan yang ditampilkan dan izinkan instalasi.
7. Setelah selesai, buka aplikasi SPADA UNTIRTA.

🛡️ Keamanan Aplikasi

- Aplikasi ini merupakan proyek independen dan bukan aplikasi resmi yang diterbitkan melalui Google Play Store.
- Karena dipasang melalui file APK dari luar Play Store, Google Play Protect mungkin menampilkan peringatan saat instalasi.
- Peringatan tersebut dapat berkaitan dengan aplikasi yang belum dikenal atau belum diverifikasi oleh Play Protect. Peringatan itu sendiri tidak membuktikan bahwa aplikasi berbahaya.
- Aplikasi ini dirancang sebagai WebView untuk membuka website SPADA UNTIRTA. Login dilakukan melalui website SPADA UNTIRTA.
- Pastikan file APK diunduh dari halaman rilis GitHub repositori ini dan periksa peringatannya sebelum melanjutkan instalasi.
