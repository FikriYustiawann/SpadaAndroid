# SPADA Untirta Android WebView

Proyek Android sederhana yang membuka https://spada.untirta.ac.id/?redirect=0 di dalam aplikasi.

## Cara membangun APK
1. Buka proyek ini dengan Android Studio di komputer.
2. Pastikan Android SDK Platform 35 dan JDK 17 tersedia.
3. Pilih **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Setelah selesai, APK debug biasanya ada di `app/build/outputs/apk/debug/app-debug.apk`.
5. Pindahkan APK ke HP Android dan instal. Jika diminta, izinkan instalasi dari sumber yang digunakan.

## Catatan
- Proyek ini adalah sumber aplikasi, bukan APK yang sudah jadi.
- Login tetap memakai sistem resmi SPADA Untirta; aplikasi tidak menyimpan atau membaca password.
- Fitur tertentu seperti unggah berkas, kamera, pop-up, atau autentikasi eksternal mungkin memerlukan penyesuaian tambahan.
- Situs harus tetap tersedia dan HP memerlukan internet.
