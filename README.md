# SPADA UNTIRTA Android

Aplikasi Android berbasis WebView untuk mengakses website [SPADA UNTIRTA](https://spada.untirta.ac.id/?redirect=0) langsung dari HP Android.

## Download Aplikasi

Unduh versi terbaru lewat tombol di atas, atau langsung dari halaman rilis:

[**Klik di sini untuk Download SPADA UNTIRTA**](https://github.com/FikriYustiawann/SpadaAndroid/releases/download/v1.0.0/SPADAUntircoy-APK.zip)

Semua versi tersedia di halaman [Releases](https://github.com/FikriYustiawann/SpadaAndroid/releases).

## Cara Instalasi

1. Klik tombol **Download SPADA UNTIRTA** di atas.
2. Tunggu file ZIP selesai diunduh.
3. Ekstrak file ZIP untuk mendapatkan file APK.
4. Buka file APK dan instal di HP Android.
5. Jika diminta, izinkan instalasi dari sumber tidak dikenal untuk aplikasi yang kamu pakai membuka file (misalnya browser atau File Manager).
6. Jika muncul peringatan Google Play Protect, baca keterangannya terlebih dahulu sebelum melanjutkan.

## Keamanan Aplikasi

- Aplikasi ini adalah **proyek independen** dan **bukan aplikasi resmi** yang diterbitkan melalui Google Play Store.
- Karena dipasang lewat file APK dari luar Play Store, Google Play Protect mungkin menampilkan peringatan saat instalasi.
- Peringatan tersebut bisa muncul karena aplikasi belum dikenal atau belum diverifikasi oleh Play Protect. Peringatan itu sendiri **tidak membuktikan** bahwa aplikasi berbahaya.
- Aplikasi dirancang sebagai WebView untuk membuka website SPADA UNTIRTA. **Login dilakukan melalui website SPADA UNTIRTA**, dan aplikasi tidak menyimpan atau membaca password.
- Pastikan file APK diunduh dari **halaman rilis GitHub repositori ini**, dan periksa peringatannya sebelum melanjutkan instalasi.

## Ctatan

- Koneksi internet diperlukan untuk menggunakan aplikasi.
- Website SPADA UNTIRTA harus tersedia agar dapat diakses melalui aplikasi.
- Beberapa fitur website (misalnya unggah berkas, kamera, atau pop-up) mungkin memerlukan penyesuaian agar berfungsi dengan baik di dalam aplikasi.
